Serve Echo

One command. The binary is the server. Rust 1.88 or newer.

cargo run --locked --bin senv -- serve --bind 127.0.0.1:8000

Flags

FlagEnvironmentDefault
--bindSENV_BIND127.0.0.1:8000
--max-sessionsMAX_CONCURRENT_ENVS8
--max-message-bytes16777216
--idle-timeout-secs120, or 0 to keep unattached sessions

GET /health returns {"status":"healthy"}. GET /metadata and GET /schema describe the Echo environment. POST /mcp creates sessions and serves tools. GET /ws carries reset, step, and state.

The Docker image listens on 0.0.0.0:8000 because it sets SENV_BIND. See the Dockerfile in the repository.

Python

Check out OpenEnv at 58d0344011fe961342706c90288f7e842b15b1c9. Install scripts/echo-client-requirements.txt from this repository into a Python 3.10+ virtualenv. Point PYTHONPATH at OpenEnv/src and OpenEnv/envs.

from echo_env import CallToolAction, EchoEnv

with EchoEnv(base_url="http://127.0.0.1:8000").sync() as env:
    env.reset()
    step = env.step(CallToolAction(tool_name="echo_message", arguments={"message": "Hello!"}))
    assert step.observation.result["data"] == "Hello!"
    assert env.state().step_count == 1

scripts/echo_compat.sh is the repeatable check. It builds senv, waits for /health, and runs that client. Set OPENENV_SRC to the checkout.

Limits

  • Disconnecting the WebSocket destroys the session. A later session/close may report an unknown id. The official client ignores that.
  • Messages stop at 16 MiB unless you raise --max-message-bytes. The Python client's default is 100 MB.
  • Echo never finishes an episode. Step reward is null. Reset reward is 0.0. seed is stored and ignored.
  • HTTP tools/list and tools/call do not increment step_count. A WebSocket step does, including a tool error after the action parsed.
  • There is no HTTP /reset, /step, or /state, no CORS, and no web UI.
  • A proof of the kernel function would not prove that two sockets are isolated. Isolation is a separate engine per session, checked by tests.
  • Non-string tool text is JSON, not Python repr.

The message shapes are in PROTOCOL.md. The architecture is in DESIGN.md.
