OpenEnv Echo · one MemoryEngine per session · Apache-2.0

Echo for OpenEnv, on h5i-app

senv serves the production Echo protocol. reset, step, and state are kernel transitions. The official Python EchoEnv client talks to this process without changes.

cargo run --locked --bin senv -- serve
Listens on 127.0.0.1:8000 OpenEnv 58d03440 h5i-app 5e0f8a92
What it does

A session is an engine.

The Axum shell parses JSON. The kernel decides the next episode. Dropping the socket drops the engine.

Official Echo client
EchoEnv.reset(), step(), and state() use the WebSocket. list_tools and call_tool use POST /mcp and do not increment step_count.
One engine per socket
Each session builds its own h5i_app::MemoryEngine. A second client cannot see the first episode. Disconnect destroys the session.
Bounded
Eight live sessions by default. A ninth create is a capacity error. Messages larger than 16 MiB are rejected. Unattached sessions expire.
Not a sandbox
senv no longer manages Python environments, uv, or an OS security boundary. The old command set is history in this git repository, not a feature of this binary.
